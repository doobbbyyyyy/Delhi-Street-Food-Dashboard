# 🌮 Delhi Street Food Dashboard

**Interactive analytics of 100+ street food vendors in Delhi NCR**

## 📊 Features
- 🔥 Top hotspots (Chandni Chowk dominates!)
- 💰 Price vs Rating trends
- ⭐ Filter by price/rating
- 🏆 Top 10 restaurants table

## 🚀 Live Demo
`streamlit run dashboard.py`

## 📈 Key Insights
- **Chandni Chowk**: Most vendors, 4.7⭐ avg
- **Sweet spot**: ₹200-400, 4.5+⭐ ratings
- **Total**: 100+ street food spots analyzed

**Built with**: Pandas • Matplotlib • Streamlit
